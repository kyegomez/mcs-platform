## File Structure

Each agent prompt file follows this standardized format:

```markdown
# Agent Name - Specialty

## Agent Information
- Name, Specialty, Description
- Icon and Color coding

## Tags
- Relevant medical tags for categorization

## System Prompt
- Complete system prompt with expertise areas
- Interaction guidelines
- Important disclaimers
```

## Usage

These prompts are designed for use with AI medical consultation systems. Each prompt:

1. **Defines Expertise**: Specific medical knowledge areas
2. **Sets Behavior**: How the agent should interact with patients
3. **Includes Safeguards**: Important disclaimers about virtual consultation limitations
4. **Maintains Standards**: Evidence-based medical information focus

## Important Notes

⚠️ **Medical Disclaimer**: All agents include appropriate disclaimers about:
- Providing general information, not diagnoses
- Encouraging consultation with healthcare providers
- Recognizing limitations of virtual consultation
- Emphasizing when emergency care is needed

🔬 **Evidence-Based**: All prompts emphasize evidence-based medical information and current medical standards.

🤝 **Patient-Centered**: Agents are designed to be empathetic, professional, and supportive while maintaining medical accuracy.

## File Naming Convention

Files are named using the pattern: `dr-[agent-name]-[specialty].md`

Examples:
- `dr-cardio-cardiovascular-health.md`
- `dr-neuro-neurology.md`
- `dr-emergency-emergency-medicine.md`
